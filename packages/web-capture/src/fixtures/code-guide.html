Ownership guide

This guide explains how a small program owns a value and passes it to another function. The examples are part of the explanation, and their captions carry information the reader may need to highlight.

In the first example we retain the complete program, including its main function. Some documentation sites wrap code in figures, so those containers must not be mistaken for decorative images and removed.

After the call returns, the owning function remains responsible for the value. These explanatory paragraphs connect the code to the diagram and should remain in their original order without synthetic whitespace changes. 

fn length(value: &str) -> usize {
    value.len()
}

The helper borrows rather than takes ownership. This final statement completes the explanation and provides a useful paragraph for checking that highlighting still locates the exact text in the saved reading copy.
