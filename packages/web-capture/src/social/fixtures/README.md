# Social DOM fixtures

Minimal, fictionalised layout fixtures. All authors, IDs, text and media URLs are
synthetic; no account sessions, page scripts or personal data are included.

Bluesky's profile and expanded-post shapes and Mastodon's status classes were
checked in an unauthenticated LAB Chromium browser on 2026-10-11. The Bluesky
expanded item deliberately has no own permalink and no `postText` test ID.
X's fixture represents its `tweet` / `User-Name` / `tweetText` DOM contract;
there was no logged-in X browser. Its explicit reply attributes model evidence
supplied by a page, not an assumption that every X timeline supplies those edges.
