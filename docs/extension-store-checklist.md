### Data-flow evidence for the disclosures

- Page URLs, titles, readable text, selected quotations, user annotations and citation metadata are captured and written to the user's authorized mdbase collection: `apps/extension/src/use-extension-capture.ts`, `apps/extension/src/page-capture.ts`, `apps/extension/src/save-capture.ts`, `packages/connect/src/source-imports.ts`. Saved-page matching also reads page URLs; this is not a blanket browsing-history export.
- Settings, authorization grants and mutation journal use `chrome.storage.local`; per-tab drafts use session storage: `apps/extension/src/chrome-storage.ts`, `apps/extension/src/background.ts`, `apps/extension/src/drafts.ts`. Do not claim all data stays on-device: authorized collection saves are network operations.
- DOI identifiers are sent to `https://doi.org/` for metadata, without cookies: `packages/web-capture/src/doi.ts`.
- Wikimedia Citoid receives a captured page address **only after explicit opt-in** (missing preference means OFF): `apps/extension/src/citoid-setting.ts`, `packages/web-capture/src/provider-claims.ts`, `packages/web-capture/src/citation-lookup.ts`. Citoid requests omit credentials; safe URL/PDF restrictions apply. This is separate from saving content to mdbase.

Current API references: [v2 publish and warning details](https://developer.chrome.com/docs/webstore/api/reference/rest/v2/publishers.items/publish), [v2 read-only status](https://developer.chrome.com/docs/webstore/api/reference/rest/v2/publishers.items/fetchStatus). No API migration to v1, warning bypass or permission removal is warranted by the available evidence.
